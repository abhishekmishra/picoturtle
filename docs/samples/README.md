# PicoTurtle Sample Programs

The canonical examples live in [`lua/samples`](../../lua/samples). Run one
from the repository root:

```sh
./build/picoturtle lua/samples/polygons.lua
```

| Sample | Purpose |
| --- | --- |
| [`turtle_basic.lua`](../../lua/samples/turtle_basic.lua) | Minimal movement |
| [`polygons.lua`](../../lua/samples/polygons.lua) | Repeated regular polygons |
| [`spiral.lua`](../../lua/samples/spiral.lua) | Incremental movement and turning |
| [`tree.lua`](../../lua/samples/tree.lua) | Recursive branching |
| [`sierpinski.lua`](../../lua/samples/sierpinski.lua) | Recursive geometry |
| [`fern.lua`](../../lua/samples/fern.lua) | Larger recursive drawing and Latin text |
| [`text-demo.lua`](../../lua/samples/text-demo.lua) | Rotated Noto Sans text |
| [`save_restore.lua`](../../lua/samples/save_restore.lua) | Turtle state stack |
| [`draw_mandrill.lua`](../../lua/samples/draw_mandrill.lua) | Drawing an image path |
| [`draw_mandrill_move.lua`](../../lua/samples/draw_mandrill_move.lua) | Reusable images and animation |
